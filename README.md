# Кинологический центр

Веб-приложение для учёта клуба собаководства и проведения выставок.
FastAPI + SQLite, один процесс, вся площадка закрыта паролем.

**Демо:** http://188.227.86.219:8315/ · пароль `dogs`

## Возможности

- **Собаки** — полная карточка: группа пород, порода, окрас, кличка, номер
  родословной, чип, клеймо, пол, дата рождения, происхождение (отец/мать —
  клички и номера родословных), заводчик, владелец. Поиск по кличке / породе /
  родословной / чипу / клейму. История участия в выставках.
- **Владельцы / члены клуба** — контакты, номер и дата членства, статус,
  быстрый переход к собакам и взносам владельца.
- **Взносы** — гибкий журнал: годовые членские и разовые (регистрация собаки,
  участие в выставке, прочее), статусы «оплачено / задолженность», сводка сумм.
- **Мероприятия (выставки, тестирования, соревнования)** — жизненный цикл:

  `Черновик → Запись открыта → Запись закрыта (каталог) → Экспертиза → Завершено`

  На каждом этапе — свои действия: запись собак с выбором класса, автоматическое
  присвоение каталожных номеров (порядок РКФ: группа → порода → пол → класс),
  проставление оценок / мест / титулов / описаний.
- **Печатные документы** (открываются отдельной страницей, печать Ctrl+P → PDF):
  каталог выставки, ринговая ведомость (пустые графы для судьи), дипломы
  (по одному на страницу), отчёт для клуба.
- **Справочники** (предзаполнены РКФ/FCI, редактируются под клуб; изменения сразу
  видны в формах):
  - **Породы** — дерево «группа FCI → порода» (10 групп, ~60 пород); добавление,
    переименование и удаление групп и пород, импорт списком;
  - **Классы / Оценки / Титулы** — простые списки с импортом списком;
  - **Ранги выставок** — у каждого ранга задаётся набор доступных оценок и титулов;
    именно они предлагаются при экспертизе и печатаются в дипломах и отчётах
    (пусто = используются все);
  - **Адреса** — общий справочник, подставляется подсказками в адрес владельца
    и место проведения выставки.

## Технически

- Backend: `app.py` — FastAPI, SQLite (`kennel.db` создаётся автоматически,
  миграции полей встроены). JSON API `/api/*`, печатные страницы `/print/*`.
- Frontend: `index.html` — одностраничное приложение на ванильном JS,
  светлая тема, адаптив (на телефоне навигация уходит в нижнюю панель).
- Авторизация: единый пароль (env `KENNEL_PASSWORD`, по умолчанию `dogs`),
  кука-сессия на 30 дней.

### Перспектива десктопа

Фронтенд статичен, API без внешних зависимостей — приложение переносится в
десктоп (Tauri / Electron / PyInstaller + локальный uvicorn) без переписывания
логики. Серверная демка — для быстрой отладки.

## Запуск локально

```bash
python -m venv venv && venv/Scripts/pip install -r requirements.txt
set KENNEL_PASSWORD=dogs
venv/Scripts/uvicorn app:app --port 8315
```

Тесты: `python _smoke.py` (создаёт временную БД, гоняет весь API и печать).

## Деплой

`python deploy_kennel.py` — заливает файлы на 188.227.86.219 и поднимает
systemd-сервис `kennel-club` на порту 8315 (см. `install.sh`).
